# KIET University Website

## Project Overview
This project is a static university website developed for Karachi Institute of Economics and Technology (KIET) as part of the Application of Information and Communication Technology Lab assignment.

The website provides basic information about KIET, its departments, academic programs, admissions, and contact details.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Website Features
- Navigation bar with working section links
- Home and About sections
- List of university departments
- Academic programs table
- Admission inquiry form
- KIET campus and classroom images
- JavaScript welcome message
- Responsive and attractive design

## How to Run the Website
1. Download or extract the project ZIP file.
2. Open the `KIET_University_Website` folder.
3. Double-click `index.html`.
4. The website will open in your default web browser.
